# Food Ordering System

Java Console Application demonstrating OOP concepts with multiple food choices and payment methods.

## Java Classes
Main.java, FoodItem.java, Customer.java, OrderItem.java, Order.java, Payment.java, UpiPayment.java, CashPayment.java

FoodOrderServlet.java is not included.

## Run
From the Java/src folder:
javac com\foodorder\*.java
java com.foodorder.Main
